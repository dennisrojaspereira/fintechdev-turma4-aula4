# Engineering Loop

IMPLEMENT → VALIDATE → BREAK → OBSERVE → COMPARE → IMPROVE → REPEAT

1. Implemente segundo a SPEC.
2. Execute testes.
3. Provoque falhas relevantes.
4. Colete logs/métricas/traces.
5. Compare com acceptance criteria.
6. Melhore somente onde houver gap.
7. Execute novamente.

Final:
| Criterion | Evidence | PASS/FAIL |

Nunca declare PASS sem evidência executada.
