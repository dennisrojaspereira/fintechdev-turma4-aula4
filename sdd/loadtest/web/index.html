SPEC-003 ao vivo — a request não espera o provedor

Experimentos de carga (k6) contra a stack do docker compose: PostgreSQL → Debezium → Kafka → worker → provedor. Cada experimento prova um acceptance criterion com thresholds: se um falhar, o k6 sai com erro e o card fica vermelho.

POST /api/v1/payments ──► 202 PENDING ──► outbox(PaymentRequested) ═WAL═► Debezium ──► Kafka ──► worker ──► PSP / PIX ──► APPROVED | DECLINED | FAILED | UNKNOWN └──► PaymentCompleted ──► ledger (idempotente)
conectando ao runner… API localhost:8090 · Connect :8084 · PSP falso :8082 · PIX falso :8083
Runner: cd sdd/loadtest && java K6Runner.java (usa o k6 local ou grafana/k6 no Docker). Resultados em sdd/loadtest/results/*.json. Um experimento por vez.
