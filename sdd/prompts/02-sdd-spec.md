# SDD / Spec

Leia `sdd/INTENT.md`.

Transforme o Intent aprovado em uma SPEC implementável e testável:
objetivo, escopo, atores, precondições, fluxo, estados, contratos,
dados, regras, erros, idempotência, observabilidade,
acceptance criteria e cenários de teste.

Não invente requisitos.
Marque perguntas bloqueantes.
