# Plan + Implement

Leia SPEC, RULES e GUARDRAILS.

Primeiro:
1. identifique ambiguidades bloqueantes;
2. crie tasks pequenas e ordenadas;
3. mostre o plano.

Não implemente se uma dúvida alterar contrato, modelo de dados,
invariante financeiro ou acceptance criterion.

Depois da aprovação:
- implemente uma task por vez;
- execute testes;
- valide acceptance criteria;
- registre evidence.

Ao final mostre arquivos, testes, comandos, resultados e riscos restantes.
