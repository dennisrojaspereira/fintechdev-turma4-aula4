# Rules

## Retry
- Máximo de 3 tentativas quando retry for permitido.
- Usar exponential backoff.
- Logar cada tentativa.
- Preservar o correlation ID.

## Engineering
- Seguir convenções existentes.
- Manter mudanças dentro da SPEC aprovada.
- Executar testes relevantes.
- Não introduzir tecnologia nova sem necessidade explícita.
