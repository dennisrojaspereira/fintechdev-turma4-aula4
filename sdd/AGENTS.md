# Agent Instructions

Antes de implementar:
1. Leia `docs/domain/payment.md`.
2. Leia `docs/architecture.md`.
3. Leia `sdd/INTENT.md`, `sdd/INTENT-002.md` e `sdd/INTENT-003.md`.
4. Leia `sdd/SPEC.md`, `sdd/SPEC-002.md` e `sdd/SPEC-003.md`.
5. Leia `sdd/RULES.md`.
6. Leia `sdd/GUARDRAILS.md`.

Não invente requisitos.
Se uma ambiguidade mudar contrato, modelo de dados, invariante financeiro ou acceptance criteria, STOP e pergunte.

Após alterações:
- execute os testes relevantes;
- valide os acceptance criteria;
- registre evidências em `sdd/EVIDENCE.md` (SPEC-001), `sdd/EVIDENCE-002.md` (SPEC-002) ou `sdd/EVIDENCE-003.md` (SPEC-003).

Nunca declare conclusão sem evidência executada.
